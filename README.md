# AIAT × Kaggle Hackathon 1/2020: COVID image (7th prize)

Notebooks from the 7th-prize entry in Hackathon 1/2020 (COVID image), run in 2020 by the Artificial Intelligence Association of Thailand (AIAT) with Kaggle.

| Notebook | What is in it |
|---|---|
| [`Code/02_PretainedModel_01.ipynb`](Code/02_PretainedModel_01.ipynb), [`Code/02_PretainedModel_1.ipynb`](Code/02_PretainedModel_1.ipynb) | The competition models: VGG19 trained from scratch, VGG19 with frozen pre-trained weights, and fine-tuned VGG19, with ImageDataGenerator augmentation and an F1-score metric (Keras) |
| [`Code/01_PretainedModel.ipynb`](Code/01_PretainedModel.ipynb) | Warm-up: a small CNN on MNIST |
| [`Code/03_PretainedModel.ipynb`](Code/03_PretainedModel.ipynb) | Practice notebook: XGBoost on tabular data combined with VGG16 image features |

The dataset and trained weights are not in the repository. They are in this [Google Drive folder](https://drive.google.com/drive/folders/1wmSPOZfsUxbslIWzzwkSJ60u_CINZgBU?usp=sharing).

The notebooks were written for Google Colab with Google Drive mounted, and use TensorFlow/Keras, scikit-learn, numpy, pandas and matplotlib.
